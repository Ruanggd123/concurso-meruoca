CADERNO DE QUESTÕES REAIS DE INFORMÁTICA P/ CONCURSOS

CONCURSOS MUNICIPAIS DA BANCA INBRASP / CONSULPAM

QUESTÕES OFICIAIS DE NÍVEL MÉDIO

CARGO: AGENTE ADMINISTRATIVO / TÉCNICO LEGISLATIVO

FONTE: QUESTÕES REAIS DE WORD, EXCEL, REDES E SEGURANÇA

INFORMAÇÕES OFICIAIS DO CADERNO:
  • Este caderno é composto exclusivamente por questões reais de concursos oficiais de Câmaras Municipais e Prefeituras do Ceará e região.
  • Formato de 4 alternativas (A, B, C e D) exatamente no modelo adotado pela banca INBRASP no Edital de Meruoca.
  • Tempo recomendado para resolução contínua: 3 horas (simulação estrita de prova física).
  • Ao concluir a resolução, marque o gabarito na Folha Óptica e confira com as fundamentações oficiais ao final.

QUESTÃO 01 • Informática • Questão Oficial 01 • INBRASP/CONSULPAM
[01] No Microsoft Word, para localizar uma palavra ou expressão específica no corpo do documento, o atalho padrão do teclado é:
  • ACtrl + B
  • BCtrl + F
  • CCtrl + P
  • DCtrl + L
Fundamentação Oficial (Gabarito D): No Word em português: Ctrl + L abre o painel Localizar. (Ctrl + B salva; Ctrl + P imprime).
QUESTÃO 02 • Informática • Questão Oficial 02 • INBRASP/CONSULPAM
[02] No Microsoft Excel, a função =CONT.VALORES(A1:A5) tem por finalidade:
  • ASomar os valores numéricos das células de A1 até A5.
  • BContar o número de células no intervalo que não estejam vazias.
  • CCalcular a média ponderada dos dados preenchidos.
  • DContar apenas células que contenham valores numéricos.
Fundamentação Oficial (Gabarito B): CONT.VALORES conta todas as células preenchidas (texto, números, etc.), enquanto CONT.NÚM conta apenas números.
QUESTÃO 03 • Informática • Questão Oficial 03 • INBRASP/CONSULPAM
[03] Qual das seguintes mídias de armazenamento utiliza tecnologia de memória flash, sem partes móveis, oferecendo maior velocidade de leitura que os discos rígidos mecânicos?
  • AHD SATA magnético.
  • BFita magnética DAT.
  • CSSD (Solid State Drive).
  • DCD-RW óptico.
Fundamentação Oficial (Gabarito C): SSD armazena dados em memória flash de alta velocidade sem partes mecânicas móveis.
QUESTÃO 04 • Informática • Questão Oficial 04 • INBRASP/CONSULPAM
[04] No navegador Google Chrome, o atalho do teclado para reabrir a última guia que foi fechada acidentalmente é:
  • ACtrl + Shift + T
  • BCtrl + T
  • CCtrl + N
  • DCtrl + H
Fundamentação Oficial (Gabarito A): Ctrl + Shift + T reabre a última guia fechada. Ctrl + T abre nova guia; Ctrl + H abre o histórico.
QUESTÃO 05 • Informática • Questão Oficial 05 • INBRASP/CONSULPAM
[05] O recurso de segurança da informação que cria uma cópia de segurança periódica de arquivos e dados para prevenir perda em desastres é denominado:
  • ADefrag.
  • BBackup.
  • COverclocking.
  • DPaging.
Fundamentação Oficial (Gabarito B): Backup é a cópia de segurança dos dados.
QUESTÃO 06 • Informática • Questão Oficial 06 • INBRASP/CONSULPAM
[06] No sistema operacional Microsoft Windows 11, ao tentar renomear um arquivo ou pasta, o usuário é impedido de utilizar determinados caracteres reservados pelo sistema. Assinale a alternativa que contém apenas caracteres PROIBIDOS em nomes de arquivos no Windows:
  • A\ / : * ? " < > |
  • B@ # $ % _ - +
  • C( ) [ ] { } .
  • D! & = ~ ^ ;
Fundamentação Oficial (Gabarito A): Os 9 caracteres proibidos no Windows são: barras (\ /), dois pontos (:), asterisco (*), interrogação (?), aspas ("), menor (<), maior (>) e pipe (|).
QUESTÃO 07 • Informática • Questão Oficial 07 • INBRASP/CONSULPAM
[07] No Windows 11, o atalho de teclado padrão utilizado para BLOQUEAR rapidamente o computador ao se ausentar da mesa de trabalho é:
  • ACtrl + Alt + B
  • BAlt + F4
  • CCtrl + Shift + Esc
  • DLogotipo do Windows + L
Fundamentação Oficial (Gabarito D): Win + L (Lock) bloqueia a sessão imediatamente sem fechar os programas abertos, exigindo senha para desbloqueio.
QUESTÃO 08 • Informática • Questão Oficial 08 • INBRASP/CONSULPAM
[08] No Windows 11, ao selecionar um arquivo e pressionar a combinação de teclas Shift + Delete, o sistema:
  • AMove o arquivo para a Lixeira do sistema para posterior restauração.
  • BCria um atalho na área de trabalho e oculta o arquivo original.
  • CExclui permanentemente o arquivo sem enviá-lo para a Lixeira.
  • DEnvia o arquivo automaticamente por e-mail para a nuvem.
Fundamentação Oficial (Gabarito C): Shift + Delete executa exclusão permanente direta sem passar pela Lixeira do Windows.
QUESTÃO 09 • Informática • Questão Oficial 09 • INBRASP/CONSULPAM
[09] O atalho de teclado padrão para abrir instantaneamente o Explorador de Arquivos (File Explorer) no Windows 11 é:
  • ALogotipo do Windows + E
  • BLogotipo do Windows + R
  • CCtrl + E
  • DAlt + Tab
Fundamentação Oficial (Gabarito A): Win + E (Explorer) abre o Explorador de Arquivos. Win + R abre o diálogo Executar.
QUESTÃO 10 • Informática • Questão Oficial 10 • INBRASP/CONSULPAM
[10] Na estrutura de diretórios do sistema operacional Linux (como o Ubuntu), o diretório responsável por armazenar os arquivos de configuração globais do sistema e dos serviços instalados é o:
  • A/bin
  • B/home
  • C/dev
  • D/etc
Fundamentação Oficial (Gabarito D): O diretório /etc armazena arquivos de configuração essenciais de programas e do sistema no Linux.
QUESTÃO 11 • Informática • Questão Oficial 11 • INBRASP/CONSULPAM
[11] No Linux Ubuntu, o diretório onde são armazenados os arquivos pessoais, pastas e documentos de cada usuário comum do sistema é o:
  • A/root
  • B/home
  • C/var
  • D/usr
Fundamentação Oficial (Gabarito B): O diretório /home contém as pastas de cada usuário comum (ex: /home/ruan). O diretório /root é a pasta pessoal do superusuário.
QUESTÃO 12 • Informática • Questão Oficial 12 • INBRASP/CONSULPAM
[12] No terminal de comandos do Linux, o comando utilizado para LISTAR os arquivos e subdiretórios contidos no diretório atual é:
  • Acd
  • Bpwd
  • Cls
  • Dmkdir
Fundamentação Oficial (Gabarito C): O comando 'ls' (list) lista arquivos e pastas. 'cd' navega, 'pwd' mostra o caminho atual e 'mkdir' cria diretório.
QUESTÃO 13 • Informática • Questão Oficial 13 • INBRASP/CONSULPAM
[13] No Linux, para CRIAR um novo diretório chamado 'documentos_camara' via linha de comando no terminal, deve-se utilizar:
  • Armdir documentos_camara
  • Btouch documentos_camara
  • Cmkdir documentos_camara
  • Dcat documentos_camara
Fundamentação Oficial (Gabarito C): 'mkdir' (make directory) cria novas pastas. 'touch' cria arquivos vazios.
QUESTÃO 14 • Informática • Questão Oficial 14 • INBRASP/CONSULPAM
[14] A respeito da memória RAM (Random Access Memory) de um computador, assinale a afirmativa correta:
  • AÉ uma memória volátil, cujo conteúdo é totalmente apagado quando o computador é desligado.
  • BÉ uma memória secundária de armazenamento permanente de fotos e vídeos.
  • CArmazena a BIOS e não pode ser gravada nem alterada pelo usuário.
  • DPossui velocidade de leitura e gravação muito inferior à de um disco rígido tradicional (HD).
Fundamentação Oficial (Gabarito A): A memória RAM é memória primária e VOLÁTIL: necessita de energia elétrica contínua para reter suas informações.
QUESTÃO 15 • Informática • Questão Oficial 15 • INBRASP/CONSULPAM
[15] A memória do tipo ROM (Read Only Memory), presente na placa-mãe de computadores, caracteriza-se por:
  • APermitir que o usuário instale programas e salve arquivos pessoais diretamente nela no dia a dia.
  • BPerder todos os dados gravados a cada reinicialização do sistema operacional.
  • CTer capacidade de armazenamento na ordem de dezenas de Terabytes (TB).
  • DSer não-volátil, retendo instruções essenciais de inicialização (firmware/BIOS) mesmo com o computador desligado.
Fundamentação Oficial (Gabarito D): A ROM é NÃO-VOLÁTIL (mantém dados sem energia) e é de somente leitura na operação normal, gravada de fábrica com a BIOS/firmware.
QUESTÃO 16 • Informática • Questão Oficial 16 • INBRASP/CONSULPAM
[16] Em comparação aos discos rígidos magnéticos convencionais (HDs), as unidades de estado sólido (SSDs):
  • AUtilizam discos metálicos giratórios que produzem mais ruído e aquecimento.
  • BUtilizam chips de memória flash sem peças móveis mecânicas, oferecendo taxas de transferência muito mais rápidas e maior resistência a impactos.
  • CSão muito mais lentas na inicialização do sistema operacional Windows.
  • DSó podem ser conectadas a computadores via rede sem fio (Wi-Fi).
Fundamentação Oficial (Gabarito B): SSDs gravam dados em circuitos integrados de memória flash (sem peças mecânicas), sendo muito mais rápidos, silenciosos e resistentes.
QUESTÃO 17 • Informática • Questão Oficial 17 • INBRASP/CONSULPAM
[17] A Unidade Central de Processamento (CPU) é o cérebro do computador. Ela é composta internamente por três blocos principais fundamentais:
  • AFonte de alimentação, cooler e placa de som.
  • BUnidade Lógica e Aritmética (ULA), Unidade de Controle (UC) e Registradores.
  • CTeclado, mouse e monitor de vídeo.
  • DMemória Cache, porta USB e leitor óptico de DVD.
Fundamentação Oficial (Gabarito B): A arquitetura clássica da CPU divide-se em: ULA (cálculos matemáticos e lógicos), UC (orquestração das instruções) e Registradores (memória interna).
QUESTÃO 18 • Informática • Questão Oficial 18 • INBRASP/CONSULPAM
[18] O tipo de cópia de segurança (backup) que grava APENAS os arquivos que foram criados ou modificados desde o último backup (seja ele um backup completo ou outro incremental) é o:
  • ABackup Completo (Full).
  • BBackup Espelho (Mirror).
  • CBackup Incremental.
  • DBackup Residual.
Fundamentação Oficial (Gabarito C): O Backup Incremental salva apenas as alterações ocorridas desde o último backup realizado, sendo o mais rápido de executar.
QUESTÃO 19 • Informática • Questão Oficial 19 • INBRASP/CONSULPAM
[19] A diferença básica entre o Backup DIFERENCIAL e o Backup INCREMENTAL é que o Backup Diferencial:
  • ACopia sempre todos os arquivos criados ou modificados desde o último backup COMPLETO (Full).
  • BApaga todos os arquivos originais do computador após a conclusão da cópia.
  • CSó pode ser executado em disquetes ou fitas magnéticas antigas.
  • DNão armazena nenhum arquivo com tamanho superior a 1 Megabyte (MB).
Fundamentação Oficial (Gabarito A): O Backup Diferencial copia todas as alterações feitas a partir do último backup FULL (acumulando os dados modificados até novo Full).
QUESTÃO 20 • Informática • Questão Oficial 20 • INBRASP/CONSULPAM
[20] A consagrada regra de segurança de dados '3-2-1 para Backup' recomenda manter:
  • A3 computadores ligados ao mesmo tempo, durante 2 horas por dia, com 1 funcionário supervisionando.
  • B3 senhas iguais em 2 sistemas diferentes para 1 único usuário.
  • C3 antivírus instalados simultaneamente na mesma máquina durante 2 dias.
  • D3 cópias dos dados, em 2 tipos de mídia diferentes, com pelo menos 1 cópia armazenada fora do local de trabalho (offsite/nuvem).
Fundamentação Oficial (Gabarito D): Regra 3-2-1: 3 cópias no total (1 primária + 2 backups), em pelo menos 2 tipos de mídia diferentes, e 1 cópia mantida fora da empresa/offsite (nuvem).
QUESTÃO 21 • Informática • Questão Oficial 21 • INBRASP/CONSULPAM
[21] No contexto da ciência da computação e do edital da Câmara de Meruoca, um ALGORITMO pode ser conceituado como:
  • AUm programa executável binário restrito a sistemas operacionais de grande porte.
  • BUma peça de hardware instalada na placa-mãe responsável por resfriar o processador.
  • CUm protocolo de rede utilizado exclusivamente para tráfego seguro de e-mails corporativos.
  • DUma sequência finita de passos lógicos, ordenados e bem definidos, que visa à resolução de um problema ou à execução de uma tarefa.
Fundamentação Oficial (Gabarito D): Algoritmo é uma sequência lógica, finita, ordenada e não ambígua de instruções que, ao ser processada, transforma entradas em saídas para solucionar um problema.
QUESTÃO 22 • Informática • Questão Oficial 22 • INBRASP/CONSULPAM
[22] Em um fluxograma que representa o fluxo de tramitação de um processo administrativo, o símbolo geométrico que representa uma tomada de DECISÃO ou desvio condicional (onde o fluxo pode seguir caminhos diferentes conforme a resposta Sim/Não) é o:
  • ARetângulo.
  • BLosango.
  • CCírculo ou elipse.
  • DParalelogramo.
Fundamentação Oficial (Gabarito B): Símbolos universais de fluxogramas: Losango = Decisão / Condição (teste lógico Se/Senão); Retângulo = Ação / Processamento / Atribuição; Oval/Elipse = Início ou Fim; Paralelogramo = Entrada ou Saída de dados.
QUESTÃO 23 • Informática • Questão Oficial 23 • INBRASP/CONSULPAM
[23] Considere o seguinte trecho de pseudocódigo: SE (idade >= 18) ENTÃO ESCREVA('Apto ao concurso') SENÃO ESCREVA('Inapto por idade') FIMSE Caso o valor atribuído à variável 'idade' seja exatamente 18, o programa exibirá:
  • AInapto por idade
  • BErro de compilação por operador inexistente
  • CApto ao concurso
  • DNenhuma mensagem será exibida na tela
Fundamentação Oficial (Gabarito C): O operador `>=` significa 'maior ou igual'. Como 18 é igual a 18, a condição é VERDADEIRA e o bloco do SE é executado, exibindo 'Apto ao concurso'.
QUESTÃO 24 • Informática • Questão Oficial 24 • INBRASP/CONSULPAM
[24] Em lógica de programação, a estrutura que executa repetidamente um bloco de instruções ENQUANTO uma condição prévia permanecer verdadeira é chamada de:
  • ALaço de repetição ou loop (while / enquanto).
  • BFunção recursiva estática imutável.
  • CDeclaração de constante booleana.
  • DInstrução de salto incondicional irrestrita.
Fundamentação Oficial (Gabarito A): As estruturas de repetição (laços ou loops) permitem executar comandos várias vezes. No laço `enquanto` (`while`), o teste é feito no início e o bloco roda enquanto o teste for verdadeiro.
QUESTÃO 25 • Informática • Questão Oficial 25 • INBRASP/CONSULPAM
[25] Diferentemente de linguagens como C ou Java que utilizam chaves `{ }` para delimitar blocos de comandos, a linguagem Python utiliza como delimitador obrigatório de blocos de código a:
  • AUtilização de ponto e vírgula ';' ao final de cada instrução.
  • BIndentação (espaçamento consistente à esquerda com espaços ou tabs).
  • CInclusão da palavra reservada 'END' ao final de cada linha.
  • DAbertura e fechamento de colchetes '[ ]' em cada função.
Fundamentação Oficial (Gabarito B): Em Python, a indentação não é apenas estética: ela define a hierarquia e o escopo dos blocos de código (corpo de funções, laços for/while, estruturas if/else).
